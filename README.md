# 🧾 OCRWinRT-CSharp

Este projeto demonstra o uso de **OCR (Reconhecimento Óptico de Caracteres)** em **C#**, utilizando a API `Windows.Media.Ocr` da Windows Runtime (WinRT). O foco é realizar a **leitura de imagens em português (pt-BR)** e extrair o texto automaticamente, salvando o resultado em um arquivo `.txt`.

---

## 🔧 Tecnologias utilizadas

- C# (.NET)
- Windows.Graphics.Imaging
- Windows.Media.Ocr
- Execução assíncrona com `async/await`
- Suporte a imagens locais (JPG)

---

## 📌 Principais recursos

- 📷 Leitura de imagem JPG local
- 🧠 Reconhecimento de texto em **português brasileiro**
- 💾 Salvamento automático do texto extraído (`saida.txt`)
- 🐞 Mensagens de debug para facilitar testes e troubleshooting

---

## 🗂️ Exemplo de uso

O sistema carrega uma imagem (exemplo: `exemplo.jpg` no diretório do projeto), executa o OCR e salva automaticamente o texto extraído em `saida.txt`.

✅ Ideal para:

- Testes rápidos de OCR
- Automações simples
- Integrações com:
  - Sistemas de digitalização
  - Sistemas de cartório
  - Ambientes jurídicos e administrativos

Este projeto foi desenvolvido como parte da minha **vitrine profissional**, com o objetivo de criar uma solução **offline, simples e eficaz** para **digitalização de documentos e automação da leitura de texto** — especialmente útil em **contextos jurídicos e administrativos**.
